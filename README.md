# 榨干考试

一个给初高中学生用的 Claude skill（技能 ID：`zhagan-kaoshi`）：把考完、批改过的试卷拍照发给 Claude，它会帮你把这张卷子榨干，变成一份看得懂的诊断、一组必须亲手重做的错题，以及一份能跨考试累积的错题档案。

各科通用，包括语文、英语、政治、历史、地理等文科。

## 它会做什么

1. **识别卷面并对账**：读出每道题的得分和扣分，把各处扣分加起来和总分核对；卷面上写的时间、卷末空白等线索也会记下来。
2. **点选确认**：用一张可以点选的确认卡问你每道错题当时的情况（没时间、没思路、中间卡住、算错、看错题……），不用打字。
3. **诊断**：给每道错题定错因（不接受"粗心"这种笼统说法），挂上知识点，找出几道错题背后的共同原因，算出"最该拿回的分"。
4. **生成报告**：一份星空风格的复盘报告，手机上能直接看，也能打印。包括得分结构、共同病因、知识点星图、错题卡（提示默认折叠）、闭卷重做单、下周行动和对答案区。
5. **错题档案**：每次复盘都会更新一份 `错题档案.json`。同一个知识点在两次以上考试中出错时，报告会指出"可能没掌握"，并告诉你回到课本哪里去补。

## 安装

**Claude 网页版、桌面版或 App**：在 [Releases](../../releases) 下载 `zhagan-kaoshi.skill`，在 Claude 的设置里找到 Skills，上传这个文件。

**Claude Code**：

```bash
git clone https://github.com/Rimbo-Eric/zhagan-kaoshi.git ~/.claude/skills/zhagan-kaoshi
```

**WorkBuddy（腾讯）**：WorkBuddy 会扫描自己的技能目录 `~/.workbuddy/skills/`，里面带 SKILL.md 的文件夹都会注册成技能。

```bash
git clone https://github.com/Rimbo-Eric/zhagan-kaoshi.git ~/.workbuddy/skills/zhagan-kaoshi
```

Windows 上一般是用户目录下的 `.workbuddy\skills\`（还没在 Windows 上验证过）。使用时请选能操作文件的模式：Ask（只读）模式和 Quick（问答）模式不能生成报告和错题档案。

## 兼容性说明

- **确认卡**：在支持表单的 Claude 应用里是一张可以点选的卡片；在 Claude Code、WorkBuddy 里会分几次弹出点选问题；都不支持时退回文字。
- **脚本**：错题档案工具需要 Python 3（只用标准库）。没有 Python 时，Claude 会直接按格式读写错题档案。
- **报告**：是一个普通的 HTML 文件，手机、电脑的浏览器都能打开。标题字体从网络加载，连不上时（例如在国内连不上 Google Fonts）页面照常显示，标题改用系统宋体。

## 怎么用

1. 把批改过的试卷拍照（或导出 PDF）发给 Claude，说一句"榨干这张卷子"或"帮我复盘这张卷子"。
2. 在确认卡里点选每道错题当时的情况。不想答也可以点"直接出结果"。
3. 拿到报告后，先做闭卷重做单，做完把结果告诉 Claude。
4. **保存好 `错题档案.json`**。下次考完把它和新试卷一起发给 Claude，或者放进 Claude 项目的文件里，就能看到跨考试的变化。

有标准答案的话一起上传，结果会更准。没有标准答案时，Claude 会自己解题并注明"AI 解答，未经核对"。

## 知识点地图

`references/knowledge-map/` 里有 9 个科目、初中和高中两个学段的知识点地图，共 1409 条。每个知识点有一个稳定的 ID，错题档案靠它做跨考试统计。

| 科目 | 依据 |
|---|---|
| 数学 | 人教A版（高中）、人教版新版（初中）目录 |
| 物理、化学、生物 | 人教版目录 |
| 语文、政治、历史 | 统编版目录 |
| 英语 | 人教版目录，语法项目以课标附录为准 |
| 地理 | 人教版目录 |

这些地图的单元和知识点是对照教育部发布的课程标准、国家中小学智慧教育平台上的教材目录整理的，核对到目录这一层，没有逐节核对正文。少数条目（主要是平台上还没有新版的九年级下册）标着"待核对"。

用的是其他版本的教材也没关系：知识点按课程标准划分，各版本通用，只是报告里不会写具体的章节号，请在自己的课本目录里找。

## 隐私

卷面上的姓名、学号、学校、班级都会被忽略，不会写进报告和错题档案。
