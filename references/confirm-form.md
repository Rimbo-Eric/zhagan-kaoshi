# 第 2 步：确认卡

学生用点选的方式回答，比照格式打字快得多，也不会因为格式不对而来回返工。本文件说明确认卡里放什么、用什么形式呈现，以及没有交互组件时怎么退回到文字。

## 目录

1. 先推断，再提问
2. 放哪些问题
3. 每类题的选项
4. 三种呈现方式（按优先级）
5. 不能出现在确认卡里的内容
6. 解读学生的回复

## 1. 先推断，再提问

能从卷面和对话里看出来的，就不要问。比如卷首写着"高三一模"，就不用问年级；学生已经上传了答案，就不放上传答案那一组。问题越少，学生越愿意填完。

## 2. 放哪些问题

按下面的顺序，只放用得上的：

| 组 | 什么时候放 | 形式 |
|---|---|---|
| 识别结果对吗？ | 每次都放。问题本身写出识别摘要：考试名、总分、扣分在哪几题、看不清的地方（带"?"） | 两张卡片："都对" / "有地方要改"（选后者会出现输入框） |
| 每道错题当时是什么情况？ | 每道错题、部分得分题、空白题各一组，按失分从高到低排列，最多 15 组 | 单选药丸，选项见第 3 节 |
| 卷面上的时间标注 | 卷面上出现了时间（如"22:20"）才放 | 文本框 |
| 标准答案 | 学生还没提供答案时放 | 文件上传加文本框 |
| 教材版本 | 档案里没有这一科的教材版本时才放（只问一次，之后记在档案里） | 单选药丸：人教版 / 人教A版 / 北师大版 / 苏教版 / 统编版 / 其他 |
| 学生没回答的上一轮问题 | 上一轮有问题学生没回答、而答案会影响诊断时才放 | 按问题选形式 |

每组的问题都写成你在问学生的口气（"第 11 题当时是什么情况？"），不要写成表单字段名（"第 11 题错因："）。

## 3. 每类题的选项

**理科（数学、物理、化学、生物）的计算题和解答题**：

没时间 · 没思路 · 中间卡住 · 算错写错 · 看错漏条件 · 概念不会 · 其他

**选择题（任何科目）**：在上面的选项基础上，加一个"拿不准没选"（多选题）或"两个选项拿不准"（单选题）。

**文科主观题（政治、历史、地理的材料题，语文和英语的阅读主观题）**：

没时间 · 不知道考什么 · 和材料对不上 · 要点没答全 · 审题偏了 · 没背或记错 · 其他

**作文（语文作文、英语写作）**：

立意偏了 · 结构松散 · 素材不够 · 语言平淡 · 没写完 · 其他

**英语客观题（完形、语法填空、阅读选择等）**：

单词不认识 · 句子没读懂 · 语法规则不会 · 上下文没联系 · 没时间 · 其他

这些选项与错因类别的对应关系见 `error-taxonomy.md` 第 2 节。

## 4. 三种呈现方式（按优先级）

**① 内联表单组件（首选）**：如果环境里有能在对话中渲染交互组件、并把提交结果作为学生下一条消息发回来的工具（例如 `show_widget`），先按该工具的要求加载表单规范（如 `read_me` 的 elicitation 模块），再以 `assets/confirm-form.html` 为样板生成确认卡。样板里的结构、header 图标、上传框图标都是组件规定的固定写法，照抄；`{{…}}` 换成真实内容；错题组按需复制。按钮文字用"提交"和"直接出结果"。

**② Artifact**：如果只能做 artifact、没法把选择直接发回对话，就做一个同样内容的 HTML artifact，底部放一个"复制我的选择"按钮，把选择拼成一行文字（格式同下面的 ③），提示学生粘贴回对话。

**③ 文字**：都没有时，用一条消息列出同样的问题，每道错题后面列出选项字母，并给出回复示例，例如：`都对。11G 14D 18A 19C。21:00 开考，22:20 做到第 14 题`。告诉学生回"直接出"也可以。

## 5. 不能出现在确认卡里的内容

确认卡只陈述事实，不给答案。不要写"漏选了 B""正确答案是 4π/3"这类内容：学生还要闭卷重做，提前知道答案，重做就失去了意义。可以写"漏选了一个正确选项""你的答案和我算的不一样"。

## 6. 解读学生的回复

表单提交后，回复大致是这样一行：

```
试卷信息 — 识别结果: 都对 · 第11题: 拿不准没选 · 第14题: 算错写错 · 第18(ii)题: 没时间 · 第19(3)题: 中间卡住 · 时间说明: 21:00 开考，22:20 做到第14题
```

- 学生点了"直接出结果"（回复里会说跳过了表单），就按卷面推测错因，所有推测都标"（推测）"。
- 某一组没填：那道题的错因按卷面推测并标注；如果是会影响结论的事实（比如时间标注的含义、绿笔写的是不是标准答案），在报告里把两种可能都写出来，并提示学生找老师确认，不要再发第二张确认卡追问。
- 学生改正了识别结果：以学生说的为准，重新对一遍总分。
