# 知识点地图说明

## 用途

每个科目一个文件（`数学.md`、`物理.md`……），给每个知识点一个稳定的 ID，并写出它在教材里的位置。错题挂上 ID 以后，跨考试统计才可靠；学生反复错同一个知识点时，报告能直接告诉他回到课本哪里去补。

## ID 规则

`<学段>-<科目码>-<两位单元号>-<两位知识点号>`，例如 `GZ-SX-15-03`。

- 学段：CZ 初中，GZ 高中。
- 科目码：SX 数学、WL 物理、HX 化学、SW 生物、YW 语文、YY 英语、ZZ 政治（初中道德与法治也用 ZZ）、LS 历史、DL 地理。
- ID 的前三段（如 `GZ-SX-15`）代表单元，脚本用它统计"反复出错的单元"。单元按教材的"章"来划分（每个学段大约 10–20 个），不要用课标里的大主题（如"函数"），否则一个单元会把函数、三角、数列、导数全包进去，"反复出错的单元"就失去了意义。语文、英语这类按能力组织的科目，单元按考查板块划分（如"文言文阅读""语法"）。

## 文件格式

```
# 数学知识点地图

> 状态：草稿 / 已核对（附说明）

## 来源
- 课程标准：……
- 教材目录：……

## 高中（教材：人教A版 2019）
| id | 单元 | 知识点 | 教材位置 |
|---|---|---|---|
| GZ-SX-15-03 | 一元函数的导数及其应用 | 导数在研究函数中的应用 | 选择性必修第二册 第五章 5.3 |
```

`scripts/archive.py` 只解析以 `| CZ-` 或 `| GZ-` 开头的表格行，以及开头的"状态："那一行。表格不要合并单元格，也不要增加列。

## 可信度

知识点的骨架应当来自教育部发布的课程标准（义务教育 2022 年版、普通高中 2017 年版 2020 年修订），教材位置应当来自人民教育出版社或国家中小学智慧教育平台上的教材目录。

每个文件开头的"状态"说明它有没有对照官方原文核对过：

- **已核对**：单元、知识点和教材位置都对照过官方来源，可以直接引用。
- **草稿**：结构按课标的主题划分，但没有逐条对照官方原文；教材位置大多写着"（待核对）"。草稿地图的 ID 照常使用，因为跨考试统计只需要 ID 稳定；但报告里引用教材位置时，按 `outputs.md` 第 6 节的写法处理，不要把"待核对"的位置当成事实告诉学生。

地图文件缺失的科目，错题只写知识点名称、不填 ID，跨考试统计按名称匹配，并在报告里说明。

## 怎样核对和补全

拿到官方的课程标准或教材目录后：

1. 逐条核对单元、知识点名称和教材位置，修正后把"（待核对）"去掉。
2. **不要改动已有的 ID，也不要重新编号**，否则已经存在的错题档案会对不上。需要新增知识点时，在该单元末尾接着编号；某条知识点确实不该存在时，保留那一行，在知识点名称后注明"（已停用）"。
3. 全部核对完后，把文件开头的状态改成"已核对"，并在"来源"里写上实际打开过的网址和核对日期。

## 学生用的不是默认版本的教材时

地图里的教材位置只对应文件里写的默认版本（例如高中数学是人教A版）。学生用别的版本（北师大版、苏教版等）时，知识点和 ID 照常使用，因为它们按课程标准划分，各版本通用；但报告里不要写章节号，只写单元名和知识点名，请学生在自己的课本目录里找。
