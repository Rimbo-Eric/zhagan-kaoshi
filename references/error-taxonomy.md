## 1. 四个一级类别

| 类别 | 定义 | 卷面上的典型信号 | 补救方向 |
|---|---|---|---|
| 基础漏洞 | 概念不清、公式定理记错、知识点没掌握、该背的没背 | 用错公式、概念混淆、关键单词不认识、史实或地理事实记错 | 回到教材补知识点，用基础题巩固 |
| 思路盲区 | 知识点会，但找不到切入点，不会把题目转化成熟悉的模型；文科表现为调动不出相关知识、答题角度不全 | 空白，或只写了开头，或方向完全错；主观题只答了一个角度 | 总结题型和通用切入点、答题角度，做同类题由易到难 |
| 习惯失误 | 会做但失分：看错、算错、漏条件、跳步、抄错、答题卡涂错、术语不规范、审题偏了 | 思路对但结果错；答案方向对但没扣住设问 | 定位具体失误类型，建立对应的检查动作 |
| 时间与策略 | 没时间做完、在某题上耗时过多、取舍不当；多选题拿不准不敢选 | 卷末连续空白、后半段字迹潦草、卷面上的时间标注显示前面用时过长 | 调整做题顺序和时间分配，做限时训练 |

一道题可以有主次两个原因，例如思路盲区导致耗时过多，进而让后面的题来不及做。写主因，次因在具体错因里提一句。

## 2. 确认卡选项对应哪个类别

确认卡的选项见 `confirm-form.md` 第 3 节。

**理科计算题、解答题，以及各科选择题：**

| 选项 | 默认类别 | 需要你进一步判断的情况 |
|---|---|---|
| 没时间 | 时间与策略 | 看前面有没有在某些题上耗时过多；结合卷面时间标注算出各部分用时 |
| 没思路 | 思路盲区 | 如果其实是不认识关键概念，改为基础漏洞 |
| 中间卡住 | 思路盲区 | 卡在某个公式上 → 基础漏洞；卡在计算上 → 习惯失误 |
| 算错写错 | 习惯失误 | 按第 3 节拆成具体的失误类型；如果卷面显示是方法错了，以卷面为准 |
| 看错漏条件 | 习惯失误（审题） | 写清是哪个条件、哪种问法 |
| 概念不会 | 基础漏洞 | 写清是哪个概念或公式 |
| 拿不准没选 / 两个选项拿不准 | 时间与策略 | 见第 4 节 |

**文科主观题（政治、历史、地理材料题，语文、英语阅读主观题）：**

| 选项 | 默认类别 | 需要你进一步判断的情况 |
|---|---|---|
| 没时间 | 时间与策略 | 同上 |
| 不知道考什么 | 思路盲区 | 设问对应哪个知识点没调动出来；如果是这个知识点根本没学会，改为基础漏洞 |
| 和材料对不上 | 思路盲区 | 是材料信息没读出来，还是读出来了但不知道对应哪个知识点 |
| 要点没答全 | 看缺的是什么 | 缺知识内容 → 基础漏洞；缺角度或层次 → 思路盲区；缺术语或格式 → 习惯失误 |
| 审题偏了 | 习惯失误（审题） | 写清设问的限定词（主体、时间、范围、"原因"还是"意义"）被忽略了哪个 |
| 没背或记错 | 基础漏洞 | 写清是哪个知识点 |

**作文（语文作文、英语写作）：**

| 选项 | 默认类别 |
|---|---|
| 立意偏了 | 思路盲区 |
| 结构松散 | 思路盲区 |
| 素材不够 | 基础漏洞（积累不足） |
| 语言平淡 | 基础漏洞（积累不足） |
| 没写完 | 时间与策略 |

**英语客观题（完形、语法填空、阅读选择等）：**

| 选项 | 默认类别 |
|---|---|
| 单词不认识 | 基础漏洞（词汇） |
| 句子没读懂 | 基础漏洞（句法） |
| 语法规则不会 | 基础漏洞（语法） |
| 上下文没联系 | 思路盲区（语篇） |
| 没时间 | 时间与策略 |

学生的说法和卷面证据矛盾时，以卷面为准，温和地指出。例如："你说是算错了，但从过程看，第二步用的是 sin 的公式，这里其实是公式记混了。"

## 3. 把"粗心"拆开

"粗心"只是一个笼统的标签。拆开以后，学生才知道下次具体该检查什么。

| 大类 | 具体类型 | 例子 | 对应的检查动作 |
|---|---|---|---|
| 审题 | 看错数字或符号；漏条件；没看清问法（"不正确的是""至少""最简"）；单位没换算；文科设问的主体、时间、范围看偏 | 题目问"不正确的是"，选了正确的那项 | 读题时圈出关键词和限定条件 |
| 计算 | 正负号；移项；小数点、约分；进位 | 87.5×100 写成 875 | 关键步骤代入验算 |
| 书写 | 抄错上一行；抄错题目数据；答案写错位置；答题卡涂错 | 选择题答案栏写成"10" | 誊写时逐项对照 |
| 表达 | 步骤跳太多被扣过程分；没写单位或结论句；术语不规范；文科要点没分条 | 物理计算题漏写单位 | 按得分点写步骤或要点 |
| 注意力 | 失误集中在卷末（疲劳、时间压力）；集中在开头（紧张） | 最后三道选择题错了两道低级题 | 调整答题节奏，开头先做有把握的题 |

## 4. 选择题的特殊情况：漏选和拿不准

多选题漏选一个正确选项，通常会得部分分；选错一个，往往是 0 分。所以"拿不准就不选"本身是合理的策略，不要把它说成错误。要提升的是把那个选项判断出来：

- 看学生在这个选项旁边写过什么。如果已经写出了关键一步、只差最后推一下，就点明"离结论只差一步"，归为时间与策略，并在共同病因里留意"推理停在离结论一步的地方"这类模式。
- 如果完全没有思路，归为思路盲区。

单选题"两个选项拿不准、最后选错"同理：看是哪两个选项之间没分清，具体错因写清楚两者的区别是什么（但不要在确认卡里提前透露哪个对）。

错题卡里不要直接写出漏掉的是哪个选项，写"漏选了一个正确选项"即可，以免学生重做时直接知道答案。

## 5. 文科主观题和作文

文科主观题的失分，几乎都能落到"得分点"上。分析步骤：

1. 有参考答案时，把它拆成一条条得分点，逐条对照学生的答案：答到了、答了一半（意思对但术语不到位）、没答。
2. 没答的得分点，按第 2 节的表判断是知识缺失、角度缺失还是表达问题。
3. 具体错因写成"漏了哪个得分点、为什么漏"，例如"只答了经济原因，漏了政治原因（设问是'背景'，需要多角度）"。

作文按评分维度看：立意（是否切题、是否深刻）、结构（层次是否清楚）、素材（是否具体、是否贴切）、语言（是否准确、是否有文采）。英语写作还要看要点是否齐全、语法和拼写错误、句式变化。具体错因要指到段落或句子，不要只写"语言平淡"。

## 6. 学生没有回答时，怎样从卷面推测

| 卷面情况 | 推测类别 |
|---|---|
| 空白，且位于卷末 | 时间与策略 |
| 空白，但不在卷末，前后题都做了 | 思路盲区（主动跳过了） |
| 写了开头就停了 | 思路盲区，卡点在停下的那一步 |
| 方法对、结果错 | 习惯失误，从过程中找出出错的那一步 |
| 用错公式或概念 | 基础漏洞 |
| 主观题要点只有一个角度 | 思路盲区 |
| 主观题答非所问 | 习惯失误（审题） |

推测出来的错因，在所有输出里标注"（推测）"，错题档案中 `source` 字段填"推测"。

## 7. 找共同病因

### 步骤

1. 按知识点 ID 给错题分组，看有没有哪一组有 2 道及以上；再按单元（ID 的前三段）分组看一遍。
2. 按一级类别分组，看哪一类丢分最多。
3. 按位置和时间看：习惯失误是否集中在后半段；卷面时间标注显示前面用了多久。
4. 追问底层能力：表面上不同题型的失分，是否需要同一种能力。各科的底层能力清单见 `subjects.md`。
5. 有错题档案时：看本次的知识点和错因在历史上出现过几次。

### 写法

> 共同病因：分类讨论不完整。证据：第 8、16、21(2) 题，共丢 14 分。三道题都是在对参数分段时漏掉了边界情况（a=0 或 Δ=0）。

先写结论，再写证据题号和丢分，最后用一句话说明为什么判断它们同源。

### 例子

**时间分配**：21:00 开考，卷面上第 14 题旁写着 22:20，说明选择填空用了 80 分钟，解答题只剩 40 分钟；最后两道解答题一道空白、一道没写完。共同病因：小题用时过长，挤掉了大题时间。

**英语**：听力 26/30、阅读 30/37.5，得分率都不低；完形 4/15、语法填空 3/15、读后续写 12/25 偏低。这三类题都要求精确理解每一个词，并能用词造句；靠跳读能应付主旨题，应付不了这三类题。共同病因：词汇只认得大概意思，不会用。

**历史**：第 3 题、第 17(2) 题、第 18 题都把事件放错了时间段（把洋务运动的内容当成了戊戌变法）。共同病因：近代史的时间线没有理清。

**反例**：第 5 题看错符号，第 14 题单位没换算。两道都属于习惯失误，但失误类型不同，不要硬合并成"粗心严重"。作为两个单点问题列出即可。

## 8. 错因的好写法和坏写法

| 坏写法 | 好写法 |
|---|---|
| 粗心 | 第 2 步移项时 -3 没变号 |
| 计算错误 | 通分时公分母算错，应为 12，写成了 18 |
| 不会 | 没想到构造函数 g(x)=f(x)-x 来比较大小 |
| 概念不清 | 把"加速度为零"当成了"速度为零" |
| 审题不仔细 | 题目问"不正确的是"，选了正确的那一项 |
| 阅读理解差 | 把 novel 理解成"小说"，这里是形容词"新颖的"（熟词生义），导致推断题选错 |
| 答得不全 | 设问问"背景"，只答了经济原因，漏了政治和思想文化两个角度 |
| 不会分析材料 | 材料二"关税自主"这个信号没读出来，没联系到"维护国家主权"这个知识点 |
| 作文写得一般 | 第三段只有观点没有例子；结尾重复开头，没有升华 |
